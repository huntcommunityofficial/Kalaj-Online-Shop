# عکس دسته‌بندی‌ها

برای جایگزینی عکس هر دسته، یک فایل با همین نام (دقیقاً) داخل همین پوشه (`public/categories/`) قرار بده:

- mobile.jpg   → عکس دسته موبایل
- laptop.jpg   → عکس دسته لپ‌تاپ
- accessories.jpg → عکس دسته لوازم جانبی
- fashion.jpg  → عکس دسته پوشاک

اگه فایلی برای یک دسته نباشد، به‌صورت خودکار همون آیکون ایموجی قبلی نمایش داده میشه (fallback خودکار در کد).

ابعاد پیشنهادی: حداقل 800x800 (مربعی) برای بهترین کیفیت.
